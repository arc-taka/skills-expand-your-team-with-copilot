# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Filter activities by category, schedule, and difficulty
- Switch between light and dark mode
- Sign up for activities

Activities without a difficulty level are available to students of all levels
and are included in the difficulty filter's **All** option.
